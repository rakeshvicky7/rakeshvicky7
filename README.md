### About

I am finishing an **M.Sc. in Computer Science** at IU International University of Applied Sciences in Berlin, after a **B.Tech in Mechanical Engineering**. That first degree still shapes how I work: establish what a system is actually doing before deciding what to change about it.

- 🔭 **Currently building** my master's thesis — an AI assistant that turns vibration measurements from industrial machinery into a structured fault diagnosis a technician can act on.
- ⚙️ **Interested in** data engineering, applied machine learning, and the layer most people skip — operating systems, networks, and where hardware meets software.
- 📐 **How I work** — I measure before I claim. Every project below reports the experiments that failed alongside the ones that worked.
- 📍 **Berlin, Germany** · open to entry-level roles from October 2026.

### Projects

Each one has a page on my site that walks through the system stage by stage — how the data was built, how the model was trained, what it actually achieves, and what would have to be true for it to go further.

| Project | What it does | Stack | Read |
|---|---|---|---|
| **[Thyroid Disease Detection](https://github.com/rakeshvicky7/cardio-thyroid-api)** | Detects an overactive thyroid from the heart rate a smartwatch records during sleep. 5,568 cases across 175 patients; **91.5% sensitivity, AUC 0.939** under patient-grouped cross-validation. | Python · LightGBM · scikit-learn | [Breakdown](https://rakeshvicky7.github.io/project-thyroid.html) |
| **[Scientific Image Forgery Detection](https://github.com/rakeshvicky7/scientific-image-forgery-detection)** | Finds regions of a research figure copied and pasted from elsewhere in the same figure. Training-free, **~1.5 s per figure on CPU**, zero false positives on 60 authentic figures. | Python · OpenCV · NumPy | [Breakdown](https://rakeshvicky7.github.io/project-forgery.html) |
| **[ElderAssist](https://github.com/rakeshvicky7/ElderAssist)** | A two-sided marketplace connecting families of elderly parents with nearby helpers. Two roles, full task lifecycle, live updates, access rules enforced in the database. | React · TypeScript · PostgreSQL | [Breakdown](https://rakeshvicky7.github.io/project-elderassist.html) · [Live app](https://elderassists.netlify.app) |
| **[Grocery Sales Data Pipeline](https://github.com/rakeshvicky7/grocery-sales-batch-data-pipeline)** | 11-task orchestrated pipeline moving **5M+ sales rows** into a queryable warehouse, safe to run twice, inside a 3.7 GB memory budget. | PySpark · Airflow · PostgreSQL · Docker | [Breakdown](https://rakeshvicky7.github.io/project-pipeline.html) |

> The pipeline project documents two experiments that produced **no** improvement — a Spark cluster that ran 3.5× slower than local execution, and JDBC partitioning that gained nothing. Both are in the write-up rather than quietly dropped.
